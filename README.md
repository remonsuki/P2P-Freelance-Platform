🚀 快速啟動指南
在開始之前，請確保您的電腦已安裝 Node.js（LTS 版本）、 React。



**快速啟動 :**

**前端 :**
1. 開啟終端機
2. cd yunbarter-app
3. npm run dev
4. 啟動成功後，終端機將顯示本地瀏覽網址（通常為 http://localhost:5173 ），您可以點擊連結或在瀏覽器中打開。

**後端:**
1. 開啟終端機
2. cd yunbarter-backend
3. node server.js
